Pada rilis kali ini, kami menghadirkan pembaruan utama pada modul manajemen risiko, perbaikan formula, serta peningkatan performa dan akurasi data pada Dashboard Proyek.

### ✨ Fitur Baru & Peningkatan (Enhancements)
- **Verifikasi Massal (Bulk Action):** Penambahan fitur verifikasi sekaligus untuk pengajuan *request* edit risiko.
- **Peningkatan Notifikasi:** Menambahkan informasi detail nama proyek pada notifikasi *request* edit risiko.
- **Manajemen User:** Perbaikan dan peningkatan pada proses sinkronisasi data *user* beserta penyesuaian UI pada tampilan form tambah dan edit *user*.

### 🐛 Perbaikan Bug (Bug Fixes)
- **Dashboard Konsolidasi Proyek:** Melakukan perbaikan *layout* dan performa pada *dashboard* konsolidasi proyek.
- **Formula Efektivitas Risiko:** Memperbaiki logika rumus efektivitas risiko (nilai yang lebih besar atau sama dengan 0 sekarang dikategorikan sebagai "Efektif").
- **Akurasi Data Laporan:** Perbaikan pada laporan konsolidasi proyek agar secara presisi mengambil data realisasi yang paling terakhir.
- **Filter Status Monitoring:** Memperbaiki anomali pada filter status *monitoring* di *list* proyek yang sebelumnya tidak sesuai.
- **Data Dashboard Proyek:** Memperbaiki *query* pengambilan data realisasi risiko pada *dashboard* proyek agar menampilkan angka yang valid dan sinkron.
- **Scoring RMI:** Perbaikan pada fungsi pemilihan *scoring* saat melakukan penilaian aspek dinamis RMI.
