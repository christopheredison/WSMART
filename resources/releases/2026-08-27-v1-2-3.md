Pada rilis kali ini dilakukan beberapa perbaikan bug serta penyesuaian pada akses dashboard konsolidasi proyek, modul proyek, modul korporat, modul laporan, dan upload file di penilaian RMI.

### ✨ Fitur Baru & Peningkatan (Enhancements)

#### Dashboard Konsolidasi Proyek
- Penyesuaian akses menu dan halaman dashboard Proyek Konsolidasi agar sesuai dengan kewenangan user.

#### Modul Proyek
- User proyek dapat mengajukan sasaran risiko lainnya dari form tambah/edit risiko, dengan persetujuan Risk Officer / Owner MR. Sasaran baru tampil setelah disetujui.
- Perbaikan status request edit pada risiko proyek.
- User hanya dapat mengubah data proyek yang menjadi tanggung jawabnya.
- Perbaikan notifikasi request edit untuk Risk Officer MR.
- Data LSP proyek yang belum tersedia otomatis diambil ulang dari API.
- Perbaikan tampilan detail realisasi risiko.

#### Modul Laporan
- Penambahan export laporan Loss Event untuk divisi dan anak perusahaan.
- Perbaikan export laporan risk register divisi, anak perusahaan, dan proyek, termasuk informasi periode penutupan pada status Closed.
- Penyesuaian kolom export dan opsi export semua divisi/anak perusahaan sesuai permission user.

### 🐛 Perbaikan Bug (Bug Fixes)

#### Modul Penilaian RMI
- Perbaikan proses upload file pada penilaian aspek kinerja.

#### Lainnya
- Perubahan istilah status KRI dari *Waspada* menjadi *Siaga* pada form, monitoring, dashboard, dan laporan.
- Perbaikan tampilan peta residual dan current risk di dashboard unit, anak perusahaan, dan korporat.
- Status Closed menampilkan tanggal/periode penutupan.
- Perbaikan filter bulan pada monitoring korporat.
- Kolom LED diubah dari tahun menjadi tanggal kejadian.
- Perbaikan tampilan detail realisasi risiko pada halaman view dan monitoring.
